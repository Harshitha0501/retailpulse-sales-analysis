# RetailPulse Sales Analysis

## 📊 Project Overview

RetailPulse Sales Analysis is a data analytics portfolio project focused on analyzing retail sales, revenue, orders, product performance, profit margins, and inventory status.

The project demonstrates practical data analysis and SQL skills using structured retail datasets, with a focus on business-oriented questions and key performance indicators (KPIs).

## 🎯 Objectives

- Analyze sales and revenue trends
- Identify high-performing products
- Analyze product profit margins
- Monitor inventory and stock status
- Calculate important business KPIs
- Use SQL to answer business questions
- Present findings in a clear and business-friendly format

## 🛠️ Tools & Technologies

- SQL
- MySQL
- Excel
- Power BI
- CSV
- Data Analysis

## 🚀 How to Use

1. Review the datasets available in the `data/` folder.
2. Open `sql/analysis_queries.sql` to review the analysis queries.
3. Run the SQL queries using MySQL.
4. Use the resulting data for analysis and reporting in Excel or Power BI.
