# RetailPulse Sales Analysis

## 📊 Project Overview

RetailPulse Sales Analysis is a data analytics portfolio project focused on
analyzing retail sales, revenue, orders, product performance, profit margins,
and inventory status.

The project demonstrates practical data analysis and SQL skills using
structured retail datasets.

## 🎯 Objectives

- Analyze sales and revenue trends
- Identify high-performing products
- Analyze product profit margins
- Monitor inventory and stock status
- Calculate important business KPIs
- Use SQL to answer business questions
- Present findings in a clear and business-friendly format
